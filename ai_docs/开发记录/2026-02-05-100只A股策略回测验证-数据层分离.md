### 2.3 修复的问题

#### 2.3.1 vt_symbol格式问题
**问题**: Exchange枚举使用错误（.SH/.SZ vs .SSE/.SZSE）

**解决方案**:
```python
def get_vt_symbol(symbol: str) -> str:
    if ".SH" in symbol:
        return symbol.replace(".SH", ".SSE")
    elif ".SZ" in symbol:
        return symbol.replace(".SZ", ".SZSE")
    return symbol + ".SZSE"
```

#### 2.3.2 数据生成器返回值问题
**问题**: 数据生成器只返回BarData列表，不返回vt_symbol

**解决方案**:
