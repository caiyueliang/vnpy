## 1. 功能概述

本次开发实现了完整的Tick数据(L2)采集器，支持A股市场Tick级别数据的采集和处理。

### 1.1 主要功能

1. **多数据源支持**
   - AKShare（免费，有限支持）
   - Tushare（付费，完整支持）
   - RQData（付费，完整支持）

2. **数据类型**
   - 实时Tick数据（买卖十档、成交明细）
   - 历史Tick数据
   - 逐笔成交数据
   - 委托队列数据

3. **实时订阅机制**
   - 支持多股票订阅
   - 回调函数注册
   - 自动轮询推送
   - 线程安全的数据缓存

## 2. 技术实现

### 2.1 核心数据结构

```python
@dataclass
class TickData:
    """Tick数据结构"""
    symbol: str                           # 股票代码
    exchange: str                         # 交易所
    datetime: datetime                    # 时间戳
    last_price: float = 0.0               # 最新价
    open_price: float = 0.0               # 开盘价
    high_price: float = 0.0               # 最高价
    low_price: float = 0.0                # 最低价
    volume: int = 0                       # 成交量
    turnover: float = 0.0                 # 成交额
    bid_prices: List[float] = field(default_factory=lambda: [0.0] * 10)
    bid_volumes: List[int] = field(default_factory=lambda: [0] * 10)
    ask_prices: List[float] = field(default_factory=lambda: [0.0] * 10)
    ask_volumes: List[int] = field(default_factory=lambda: [0] * 10)
```

### 2.2 核心方法

| 方法 | 功能 | 说明 |
|------|------|------|
| `connect()` | 连接数据源 | 支持AKShare/Tushare/RQData |
| `get_tick_data()` | 获取历史Tick | 按时间范围获取 |
| `get_realtime_tick()` | 获取实时Tick | 最新行情快照 |
| `subscribe()` | 订阅实时数据 | 支持多股票 |
| `start_realtime()` | 启动推送 | 自动轮询 |
| `resample_to_bar()` | 重采样 | Tick转K线 |

### 2.3 辅助功能

1. **买卖盘分析**
   - `get_spread()`: 获取买卖价差
   - `get_mid_price()`: 获取中间价
   - `get_bid_ask_imbalance()`: 买卖盘不平衡度

2. **数据统计**
   - `get_tick_statistics()`: Tick统计信息
   - `get_cached_tick()`: 获取缓存数据

## 4. 使用示例

### 4.1 基础使用

```python
from data.collectors import TickCollector, CollectorConfig, DataSource

# 创建采集器
collector = TickCollector(CollectorConfig(source=DataSource.AKSHARE))

# 连接数据源
if collector.connect():
    # 获取实时Tick
    tick = collector.get_realtime_tick("000001.SZ")
    print(f"最新价: {tick.last_price}")
    print(f"买卖价差: {tick.get_spread()}")
    print(f"买卖不平衡度: {tick.get_bid_ask_imbalance()}")
```

### 4.2 实时订阅

```python
# 定义回调函数
def on_tick(tick):
    print(f"{tick.symbol}: {tick.last_price}")

# 注册回调
collector.register_callback(on_tick)

# 订阅股票
collector.subscribe(["000001.SZ", "000002.SZ"])

# 启动实时推送
collector.start_realtime(interval=1.0)

# ... 运行一段时间后停止
collector.stop_realtime()
```

### 4.3 历史数据获取

```python
from datetime import datetime, timedelta

# 获取历史Tick数据
end = datetime.now()
start = end - timedelta(days=1)
ticks = collector.get_tick_data("000001.SZ", start, end)

# 转换为K线
df = collector.resample_to_bar(ticks, interval="5min")
```

## 6. 注意事项

### 6.1 数据源限制

1. **AKShare**
   - 免费使用
   - 不支持历史Tick数据
   - 仅支持当日分时数据
   - 五档行情（非十档）

2. **Tushare**
   - 需要付费权限
   - 支持历史Tick数据
   - 数据质量高

3. **RQData**
   - 需要付费权限
   - 支持完整L2数据
   - 包含十档行情

### 6.2 使用建议

- 回测场景：使用Tushare或RQData获取历史数据
- 实盘场景：使用AKShare获取实时数据（免费）
- 生产环境：建议使用付费数据源确保数据质量
