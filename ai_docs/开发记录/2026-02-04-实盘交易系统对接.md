## 二、技术实现

### 2.1 模块架构

实盘交易模块位于 `alphax/live_trading/` 目录下，包含以下核心组件：

```
alphax/live_trading/
├── __init__.py          # 模块导出
├── gateway_adapter.py   # 网关适配器
├── order_manager.py     # 订单管理系统
├── position_manager.py  # 持仓管理系统
├── account_manager.py   # 资金管理系统
└── live_engine.py       # 实盘交易引擎
```

### 2.2 核心功能实现

#### 1. GatewayAdapter - 网关适配器

**功能**: 统一封装不同券商网关的接口，提供一致的操作方式

**支持网关类型**:
- CTP - 期货CTP网关
- XTP - 股票XTP网关
- OES - OES网关
- TORA - 华鑫TORA网关
- DBF - DBF网关
- REM - REM网关
- CUSTOM - 自定义网关

**核心功能**:
- 网关状态管理（DISCONNECTED/CONNECTING/CONNECTED/ERROR/RECONNECTING）
- 自动重连机制（可配置重连间隔和最大重连次数）
- 统一的事件回调接口（on_tick/on_order/on_trade/on_position/on_account）
- 数据缓存（Tick/Order/Trade/Position/Account/Contract）
- 订单操作（send_order/cancel_order）
- 查询操作（query_account/query_position）

**代码规模**: 约660行

#### 2. OrderManager - 订单管理系统

**功能**: 订单生命周期管理、状态跟踪和风险控制

**核心功能**:
- 订单阶段跟踪（CREATED/SUBMITTING/SUBMITTED/PARTIAL/FILLED/CANCELLED/REJECTED）
- 订单状态监控和超时处理
- 风控限制检查：
  - 最大待处理订单数（默认100）
  - 每分钟最大订单数（默认60）
  - 每品种最大订单数（默认10）
- 自动撤销超时订单
- 订单历史记录
- 多维度查询（按品种/策略/状态）

**代码规模**: 约730行

#### 3. PositionManager - 持仓管理系统

**功能**: 实时持仓跟踪、持仓盈亏计算和持仓风险控制

**核心功能**:
- 持仓数据同步（从PositionData更新）
- 成交驱动的持仓更新
- 实时盈亏计算（基于最新Tick价格）
- 持仓限制检查：
  - 最大持仓市值限制
  - 最大持仓比例限制（默认20%）
- 净持仓计算
- 持仓市值统计
- 浮动盈亏/已实现盈亏计算

**代码规模**: 约650行

#### 4. AccountManager - 资金管理系统

**功能**: 账户资金监控、可用资金计算和资金使用风险控制

**核心功能**:
- 账户数据同步（从AccountData更新）
- 多账户资金汇总
- 策略资金分配机制
  - allocate_funds - 分配资金给策略
  - release_funds - 释放策略资金
  - use_funds - 使用策略资金
  - free_funds - 释放已用资金
- 资金限制检查：
  - 最小现金比例（默认10%）
  - 最大保证金比例（默认80%）
- 低资金预警
- 保证金预警

**代码规模**: 约650行

#### 5. LiveTradingEngine - 实盘交易引擎

**功能**: 整合所有模块，提供完整的实盘交易功能

**核心功能**:
- 引擎初始化和启动/停止
- 统一的交易接口（send_order/cancel_order）
- 风控检查整合（持仓限制+资金限制+策略资金限制）
- 事件流处理（Tick/Order/Trade/Position/Account）
- 策略资金分配管理
- 完整的状态报告

**代码规模**: 约590行

## 四、接口说明

### 4.1 初始化引擎

```python
from vnpy.event import EventEngine
from alphax.live_trading import LiveTradingEngine, GatewayConfig, GatewayType

# 创建事件引擎
event_engine = EventEngine()

# 创建实盘引擎
live_engine = LiveTradingEngine(event_engine)

# 配置网关
gateway_config = GatewayConfig(
    gateway_type=GatewayType.CTP,
    gateway_name="CTP",
    user_id="your_user_id",
    password="your_password",
    broker_id="your_broker_id",
    td_address="180.168.146.187:10101",
    md_address="180.168.146.187:10111",
)

# 初始化（传入网关类）
from vnpy.gateway.ctp import CtpGateway
live_engine.initialize(CtpGateway, gateway_config)

# 启动引擎
live_engine.start()
```

### 4.2 发送订单

```python
from vnpy.trader.constant import Direction, Offset

# 发送买入订单
order = live_engine.send_order(
    vt_symbol="IF2503.CFFEX",
    direction=Direction.LONG,
    offset=Offset.OPEN,
    price=3800.0,
    volume=1,
    strategy_name="MyStrategy"
)

if order:
    print(f"订单已发送: {order.vt_orderid}")
```

### 4.3 撤销订单

```python
# 撤销单个订单
live_engine.cancel_order(order.vt_orderid)

# 撤销所有订单
cancelled = live_engine.cancel_all_orders()

# 撤销指定策略的所有订单
cancelled = live_engine.cancel_all_orders(strategy_name="MyStrategy")
```

### 4.4 资金分配

```python
# 给策略分配资金
live_engine.allocate_funds("MyStrategy", 1000000.0)

# 释放策略资金
live_engine.release_funds("MyStrategy", 500000.0)
```

### 4.5 查询状态

```python
# 获取引擎状态
status = live_engine.get_status()

# 获取完整报告
report = live_engine.get_full_report()

# 获取活跃订单
active_orders = live_engine.get_active_orders()

# 获取持仓
positions = live_engine.get_all_positions()

# 获取净持仓
net_position = live_engine.get_net_position("IF2503.CFFEX")
```
