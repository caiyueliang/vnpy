## 1. 功能概述

本次开发实现了完整的消息队列系统，支持多种消息队列后端，提供统一的消息总线接口，支持自动故障转移和降级。

### 1.1 主要功能

1. **多后端支持**
   - RabbitMQ（推荐，功能完整）
   - Kafka（高吞吐量场景）
   - Redis Pub/Sub（降级方案）

2. **消息总线功能**
   - 统一的消息接口
   - 自动后端选择
   - 故障转移机制
   - 消息广播

3. **消息类型**
   - 交易消息（TRADE）
   - 订单消息（ORDER）
   - 行情数据（MARKET_DATA）
   - 策略信号（SIGNAL）
   - 风险告警（RISK_ALERT）
   - 系统消息（SYSTEM）
   - 日志消息（LOG）
   - 心跳消息（HEARTBEAT）

## 2. 技术实现

### 2.1 项目结构

```

├── base.py              # 消息队列基类和消息定义

└── message_bus.py       # 消息总线
```

### 2.2 核心数据结构

```python
@dataclass
class Message:
    """消息数据结构"""
    msg_type: MessageType              # 消息类型
    payload: Dict[str, Any]            # 消息内容
    msg_id: str                        # 消息ID
    timestamp: datetime                # 时间戳
    source: str                        # 消息来源
    target: str                        # 消息目标
    priority: int                      # 优先级（0-9）
```

### 2.3 消息队列基类

| 方法 | 功能 | 说明 |
|------|------|------|
| `connect()` | 连接消息队列 | 建立连接 |
| `disconnect()` | 断开连接 | 关闭连接 |
| `publish()` | 发布消息 | 发送消息到队列 |
| `subscribe()` | 订阅消息 | 注册回调函数 |
| `unsubscribe()` | 取消订阅 | 移除回调 |
| `declare_queue()` | 声明队列 | 创建队列 |
| `delete_queue()` | 删除队列 | 移除队列 |

## 4. 消息总线

### 4.1 功能特性

**文件**: `alphax/messaging/message_bus.py`

1. **多后端管理**
   - 自动连接多个后端
   - 主备后端切换
   - 后端健康检查

2. **故障转移**
   - 自动检测后端故障
   - 自动切换到备用后端
   - 订阅恢复机制

3. **优先级**
   - RabbitMQ > Kafka > Redis

### 4.2 使用示例

```python
from alphax.messaging import (
    MessageBus, BackendType, QueueConfig,
    MessageType, get_message_bus
)

# 配置各后端
configs = {
    BackendType.RABBITMQ: QueueConfig(
        host="localhost",
        port=5672,
        username="guest",
        password="guest"
    ),
    BackendType.REDIS: QueueConfig(
        host="localhost",
        port=6379
    )
}

# 获取消息总线实例
bus = get_message_bus(configs)

# 连接（自动选择可用后端）
if bus.connect():
    print("消息总线连接成功")
    
    # 订阅消息
    def on_trade(message):
        print(f"收到交易消息: {message.payload}")
    
    bus.subscribe("trade_queue", MessageType.TRADE, on_trade)
    
    # 发送交易信号
    bus.create_trade_signal(
        strategy_name="MomentumStrategy",
        symbol="000001.SZ",
        action="buy",
        volume=1000,
        price=10.5
    )
    
    # 发送风险告警
    bus.create_risk_alert(
        alert_type="drawdown",
        level="high",
        description="最大回撤超过10%"
    )
```

## 7. 使用建议

### 7.1 生产环境

**推荐配置**:
- 主后端: RabbitMQ
- 备用后端: Redis

**理由**:
- RabbitMQ功能完整，支持消息确认和持久化
- Redis作为降级方案，确保系统可用性

### 7.2 高吞吐量场景

**推荐配置**:
- 主后端: Kafka
- 备用后端: RabbitMQ

**理由**:
- Kafka适合大数据量处理
- RabbitMQ作为备用确保可靠性

### 7.3 开发测试

**推荐配置**:
- 使用Redis即可
- 部署简单，无需额外服务
