## 4. 数据表结构

### 4.1 时序数据库表（market_data.db）

#### bar_data - K线数据表
| 字段名 | 类型 | 说明 |
|-------|------|------|
| vt_symbol | VARCHAR | 合约代码（如：600519.SSE） |
| interval | VARCHAR | K线周期（1m, 5m, 15m, 30m, 1h, d, w, m） |
| datetime | DATETIME | 时间戳 |
| open_price | DECIMAL | 开盘价 |
| high_price | DECIMAL | 最高价 |
| low_price | DECIMAL | 最低价 |
| close_price | DECIMAL | 收盘价 |
| volume | DECIMAL | 成交量 |
| turnover | DECIMAL | 成交额 |
| open_interest | DECIMAL | 持仓量 |

#### tick_data - Tick数据表
| 字段名 | 类型 | 说明 |
|-------|------|------|
| vt_symbol | VARCHAR | 合约代码 |
| datetime | DATETIME | 时间戳 |
| last_price | DECIMAL | 最新价 |
| volume | DECIMAL | 成交量 |
| turnover | DECIMAL | 成交额 |
| bid_price_1 | DECIMAL | 买一价 |
| bid_volume_1 | DECIMAL | 买一量 |
| ask_price_1 | DECIMAL | 卖一价 |
| ask_volume_1 | DECIMAL | 卖一量 |

### 4.2 关系数据库表（trading_data.db）

| 表名 | 用途 |
|-----|------|
| trades | 交易记录表 |
| orders | 订单记录表 |
| positions | 持仓记录表 |
| account | 账户资金表 |
| strategies | 策略配置表 |
| daily_returns | 每日收益表 |

## 6. 数据类型说明

### 6.1 行情数据
- **K线数据**：支持分钟级（1m, 5m, 15m, 30m）、小时级（1h）、日级（d）、周级（w）、月级（m）
- **Tick数据**：逐笔成交数据，包含买卖盘信息
- **实时行情**：当前价格、涨跌幅、成交量等

### 6.2 基本面数据
- 财务报表（资产负债表、利润表、现金流量表）
- 股票基本信息（行业、市值、PE、PB等）
- 财务指标（ROE、ROA、毛利率等）

### 6.3 资金流向数据
- 主力资金流向
- 北向资金（沪深港通）
- 大单追踪

### 6.4 另类数据
- 新闻舆情数据
- 行业数据
- 宏观经济数据

## 7. 数据访问方式

### 7.1 通过数据库管理器访问
```python
from data.storage.database import DatabaseManager

db = DatabaseManager()
# 获取K线数据
bars = db.get_bar_data(vt_symbol="600519.SSE", interval="1m", start_date="2024-01-01")
# 获取Tick数据
ticks = db.get_tick_data(vt_symbol="600519.SSE", start_date="2024-01-01")
```

### 7.2 通过采集器获取数据
```python
from data.collectors.rqdata_collector import RQDataCollector

collector = RQDataCollector()
# 下载历史数据
collector.download_history_data(vt_symbol="600519.SSE", interval="d", start_date="2024-01-01")
```

## 9. 注意事项

1. **数据库文件生成时机**：`market_data.db` 和 `trading_data.db` 在首次运行数据采集或交易程序时自动生成
2. **数据备份**：建议定期备份 `data\` 目录下的数据库文件
3. **数据源权限**：使用 RQData、Tushare 等商业数据源需要相应的API权限
4. **存储空间**：Tick数据量较大，需关注磁盘空间使用情况
